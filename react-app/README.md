# react-app

This folder contains a small Vite + React example integrated into the repository.

Quick start:
1. cd react-app
2. npm install
3. Create a local .env (not committed) with:
   VITE_API_BASE_URL=https://your-mockapi.example.com
4. npm run dev

Notes:
- The app uses Axios and a small custom hook (hooks/useItems.js) to demonstrate GET/POST/PUT/DELETE.
- If you don't have an API yet, create one at https://mockapi.io and set VITE_API_BASE_URL accordingly.
